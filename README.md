# SodaYa-Hexagonal
Plataforma multi-inquilino donde sodas gestionan menús y pedidos. API REST en Laravel 13/PostgreSQL, SPA Vue 3/TS, Stripe, cocina en tiempo real, IA y CI/CD. Desarrollada bajo Arquitectura Hexagonal y DDD, aplicando principios SOLID para lograr alta cohesión y bajo acoplamiento en producción.
